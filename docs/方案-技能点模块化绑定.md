# 技能点模块化绑定 · 改造方案

> 来源：海龙老师 2026-09-29 的两条要求。
> 状态：**已实施**（后端 + 教师端；学生端进度自动跟随，无需改页面）。
> 说明：本方案在"技能点亮"这一条上**取代**《需求定稿-技能与证书.md》里"项目级绑定 + 完成项目点亮"的口径。

## 一、要解决的问题

海龙老师的要求拆成 8 条：

1. 技能要绑到项目的**具体模块**，不是只绑整个项目；
2. 模块与技能是**多对多**（一个模块多个技能、一个技能多个模块）；
3. 技能点亮按**对应模块的得分**判断；
4. 教师端能查**哪些技能没有对应项目或岗位**；
5. 已建项目和岗位都要能修改、能增删技能；
6. 修改项目/岗位时，**绑定不全的技能要高亮**（缺岗位或缺项目）；
7. **不能直接新建技能**，只能通过项目或岗位创建/修改时添加；
8. 技能要有简要描述，**点击或鼠标悬浮时显示**。

## 二、现状差距

| 要求 | 现状 |
| --- | --- |
| 技能绑到项目模块 | 只有项目级 `project_skill`；关卡 `project_module` 没有技能字段 |
| 模块↔技能多对多 | 不存在 |
| 按模块得分点亮 | 现在是"完成项目数 ÷ 关联项目总数"，与模块得分无关 |
| 未绑定技能可见 | 无清单、无接口 |
| 项目/岗位可增删技能 | 已具备（项目编辑、岗位编辑里都能选技能点） |
| 绑定不全高亮 | 无 |
| 不能直接新建技能 | 技能管理页有「＋ 新建技能点」，可独立创建 |
| 描述字段 / 点击显示 | 字段已有；学生端技能树点开能看描述。**悬浮提示没有**，岗位/项目选技能的下拉里也看不到描述 |

## 三、目标口径（建议）

### 3.1 绑定层级

技能绑在**项目里的关卡**上（`project_module`），原因：同一个模块库模板在不同项目里承担的技能可能不同，绑在项目关卡更贴合实际。

模块库模板（`project_stage_template`）上可以放"默认技能"作为新建项目时的预填值，作为二期增强，不进一期。

### 3.2 技能点亮算法

```text
该技能关联的模块 = 所有已发布项目里、挂了该技能的关卡（跨项目汇总）
某个模块达标 = 该关卡的得分率 ≥ 及格线
            得分率 = 该关卡得分 ÷ 该关卡权重 × 100
技能进度 = 达标模块数 ÷ 关联模块数 × 100
进度 100% → 技能点亮
```

逐关得分已经存在库里：`review_record.dimension_json` 里每个关卡一条 `{name, score, weight, reason}`，`name` 就是关卡名，可与 `project_module` 对应。所以不需要新增采集，只需要改算法。

## 四、数据模型改造

### 4.1 新增：项目关卡 ↔ 技能点

```text
project_module_skill
  id
  project_module_id   → project_module.id
  skill_node_id       → skill_node.id
  created_at
  unique(project_module_id, skill_node_id)
  index(skill_node_id)
```

### 4.2 保留但改为派生：project_skill

`project_skill` 不再手工维护，改为"该项目所有关卡技能的并集"，由后端自动汇总，避免同一份关系在两处各写一遍导致不一致。

### 4.3 新增（建议）：学生模块达成快照

```text
student_module_achievement
  id
  student_id          → sys_user.id
  project_module_id   → project_module.id
  score / weight      该模块的得分与权重
  percent             得分率
  passed              是否达标
  source              AI / TEACHER
  achieved_at
  unique(student_id, project_module_id)   只保留最新/最高一次
```

作用：技能进度不用每次去翻评审记录的 JSON，查询快、可追溯"这个技能为什么点亮/没点亮"。如果一期想省事，也可以先从 `review_record` 现算，等数据量上来再加这张表。

### 4.4 可选二期：模块库模板的默认技能

```text
stage_template_skill
  id, template_id, skill_node_id
```

## 五、接口改造

新增/调整：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/projects/{id}/modules/{module_id}/skills` | 查某个关卡的技能 |
| PUT | `/projects/{id}/modules/{module_id}/skills` | 覆盖式设置该关卡技能 |
| GET | `/skill-nodes/unbound?missing=job\|project\|both` | 未绑定技能清单（缺岗位/缺项目/两端都缺） |
| POST | `/skill-nodes` | 保留，但改为**只能**由项目/岗位编辑流程调用（带来源参数），技能管理页不再直接暴露 |
| 项目详情 | `/projects/{id}` | 返回每个关卡的技能与绑定状态 |
| 技能进度重算 | `/students/{id}/skills/recalculate` | 已存在，算法换成模块口径 |

## 六、教师端改造

1. **项目编辑弹窗**：从"项目整体选技能"改成"每个关卡下面选技能"；技能下拉支持输入即新建（新建时必须选所属技能体系）。
2. **技能选项高亮**：下拉里，两端绑定不全的技能加醒目提示（缺岗位/缺项目）。
3. **技能管理页**：
   - 增加"绑定状态"列与筛选（缺岗位 / 缺项目 / 两端都缺）；
   - 下线「＋ 新建技能点」按钮，改为提示"请在项目或岗位里创建技能点"；
   - 描述在列表里可点开查看。
4. **岗位编辑弹窗**：技能选择同样标出绑定不全的项。
5. **描述展示**：技能下拉的每一条显示"名称 + 简述"，鼠标悬浮或点击显示完整描述。

## 七、学生端改造

- 技能进度、点亮状态改为后端新口径（前端不用改算法，只展示）。
- 技能详情里补充"这个技能由哪些项目的哪些关卡培养"，让点亮依据可解释。
- 技能描述在悬浮/点击时可见。

## 八、老数据与迁移

现有 86 条"项目-技能"关系要迁移到关卡级，建议规则：把项目级技能**复制到该项目下的每一个关卡**（这样技能关联的模块数 = 项目数 × 关卡数），然后重算所有学生的技能进度。

必须提前说明的两点影响：

1. 进度会变化：原来按"完成项目数"算，现在按"达标关卡数"算，数字会不一样；
2. 证书点亮依赖技能进度，口径一变，未发证的证书点亮状态会跟着变。**已发放的证书不受影响**（证书记录是快照）。

## 九、对已做功能的影响

| 已有功能 | 影响 |
| --- | --- |
| 证书点亮判定 | 依赖技能进度，口径变化后自动跟着变，逻辑不用改 |
| 岗位推荐（匹配度 = 岗位技能点进度均值） | 自动跟着新口径变 |
| 技能树进度、成长中心 | 自动跟着变 |
| 已发放证书 | 无影响 |

## 十、分期建议

- **P0（核心）**：`project_module_skill` 建表 + 项目编辑改成按关卡绑技能 + 技能进度换模块口径 + 老数据迁移与重算。
- **P1（海龙老师明确要求的体验）**：未绑定技能清单 + 高亮 + 下线"直接新建技能点" + 技能描述悬浮/点击显示。
- **P2（增强）**：模块库模板默认技能、迁移向导、技能详情里展示关联关卡。

## 十一、最终口径（已确认并实施）

1. 技能绑在**项目里的关卡**（`project_module_skill`），模块库模板不参与。
2. 达标线跟**成长规则**走：按项目层级读 `growth_rule.pass_score`（默认 60），
   达标 = 该关卡得分率（得分 ÷ 权重 × 100）≥ 及格线。
3. 取分：同一次提交**教师定稿优先于 AI**；同一关卡取**历史最高**得分率。
   若评审只给了总分、没有逐关维度，则按总分判定该项目下每个关卡。
4. 分母维持原规则：**跨项目所有关联关卡**汇总（达标关卡数 ÷ 关联关卡数）。
5. **只进不退**：技能一旦点亮（`mastered_at`）就保持点亮，新增项目 / 关卡不再撤销；
   只有"所有达标关卡都被改判成不通过"时才真正回退。
6. 新建技能点必须指定所属技能体系；只能在项目关卡或岗位编辑里创建，
   技能管理页不再提供"直接新建"入口（名称重名会复用已有技能点）。

  `GET /skill-node-bindings`（缺岗位 / 缺项目 / 两端都缺）。
- 技能进度算法改写（`app/services/skill.py`），按关卡得分率计算。

教师端：

- 项目编辑：界面上只放**一个项目级的"关联技能点"选择框**（可多选、可搜索、选项带说明并标出
